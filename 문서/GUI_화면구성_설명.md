# DWTA 시뮬레이션 GUI 화면 구성 및 기능 설명

## 전체 구성 개요

DWTA 시뮬레이션은 **2개의 주요 윈도우**로 구성됩니다:
1. **제어 패널 (Control Panel)**: 시뮬레이션 제어 및 상태 모니터링
2. **시각화 윈도우 (Visualization Window)**: 실시간 전술 상황 및 분석 결과 표시

---

## 1. 제어 패널 (Control Panel)

### 1-1. SIMULATION CONTROL (시뮬레이션 제어)

#### **목적함수 선택**
```
┌─────────────────────────────────────┐
│ 목적함수: [MIN_DAMAGE      ▼]      │
└─────────────────────────────────────┘
```

**기능**:
- 최적화 목적함수 선택
- **MIN_DAMAGE**: 기댓값 손실 최소화 (기본값)
  - 목적: `min Σ B_i × (1 - P_survival_i)`
  - 고가치 자산 우선 방어
- **MAX_KILLS**: 요격 성공 확률 최대화
  - 목적: `max Σ P_kill_i`
  - 요격 성공률 극대화

**사용 시나리오**:
- 중요 자산 방어: MIN_DAMAGE
- 포화 공격 대응: MAX_KILLS

---

#### **시뮬레이션 속도 조절**
```
┌─────────────────────────────────────┐
│ 속도: [████████░░░░░░░░] 1.0x      │
└─────────────────────────────────────┘
```

**기능**:
- 시뮬레이션 재생 속도 조절
- 범위: 0.1x ~ 5.0x
- 기본값: 1.0x (실시간)

**사용법**:
- 슬라이더 드래그로 속도 조절
- 빠른 분석: 2.0x ~ 5.0x
- 상세 관찰: 0.5x ~ 1.0x

---

#### **시뮬레이션 시간 설정**
```
┌─────────────────────────────────────┐
│ 최대 시간(초): [1600        ▼]     │
└─────────────────────────────────────┘
```

**기능**:
- 시뮬레이션 종료 시간 설정
- 기본값: 800초
- 범위: 600 ~ 2000초

**설정 가이드**:
- 800초: 표준 시나리오 (15개 위협)
- 1200초: 장시간 교전 시나리오
- 1600초: 대규모 포화 공격 시나리오

---

#### **제어 버튼**
```
┌──────────┬──────────┬──────────┬──────────┐
│ ▶ 시작   │ ⏸ 일시정지│ ⏹ 정지   │ 🔄 리셋  │
└──────────┴──────────┴──────────┴──────────┘
```

**기능**:

1. **▶ 시작 (Start)**
   - 시뮬레이션 시작 또는 재개
   - 초기 상태에서 클릭 시 새 시뮬레이션 시작
   - 일시정지 상태에서 클릭 시 재개

2. **⏸ 일시정지 (Pause)**
   - 현재 상태에서 시뮬레이션 일시 중지
   - 전술 상황 분석 시 유용
   - 재개 가능

3. **⏹ 정지 (Stop)**
   - 시뮬레이션 완전 종료
   - 최종 통계 표시
   - 재시작 필요

4. **🔄 리셋 (Reset)**
   - 모든 설정 초기화
   - 새로운 시나리오 생성
   - 통계 초기화

### 1-2. REAL-TIME STATUS (실시간 상태)

```
┌─────────────────────────────────────────────────────────────┐
│ ● 현재 시간:  T=0          ● 할당 위협:  할당 위협: 0      │
│ ● 요격 실패:  요격 실패: 0  ● 성공률:    성공률: 0%        │
│                            ● 요격성공 값:  요격성공: -     │
│ ● 요격 성공:  요격 성공: 0  ● 궤적 성공:  요격 성공: 0     │
└─────────────────────────────────────────────────────────────┘
```

#### **상태 지표 설명**

**1. 현재 시간 (Current Time)**
```
● 현재 시간: T=375
```
- 시뮬레이션 경과 시간 (초)
- 실시간 업데이트 (1초 간격)
- 색상: 녹색 (진행 중)

**2. 할당 위협 (Assigned Threats)**
```
● 할당 위협: 할당 위협: 8
```
- 현재 포대에 할당된 활성 위협 수
- DWTA 최적화 결과 반영
- 색상: 청록색

**3. 요격 성공 (Intercepted)**
```
● 요격 성공: 요격 성공: 5
```
- 성공적으로 요격된 위협 수
- 누적 통계
- 색상: 녹색

**4. 요격 실패 (Missed)**
```
● 요격 실패: 요격 실패: 1
```
- 요격 실패한 위협 수
- 자산 피해 발생
- 색상: 주황색

**5. 궤적 성공 (Deviated)**
```
● 궤적 성공: 요격 성공: 2
```
- 궤적 이탈로 자연 무력화된 위협 수
- 0.2% 확률로 발생
- 색상: 청록색

**6. 성공률 (Success Rate)**
```
● 성공률: 성공률: 83%
```
- 전체 요격 성공률
- 계산: (요격 성공 + 궤적 이탈) / 총 위협 × 100%
- 색상: 녹색

**7. 요격성공 값 (Optimization Value)**
```
● 요격성공 값: 요격성공: 15.3
```
- 현재 목적함수 값
- MIN_DAMAGE: 기댓값 손실
- MAX_KILLS: 요격 확률 합
- 색상: 파란색

```
  - 주황색: 할당됨 (포대 할당)
  - 빨간색: 요격 실패
  - 회색: 요격 성공 (사라짐)
라벨: 위협 ID (T01, T08 등)
```

**기능**:
- 실시간 위치 업데이트
- 비행 궤적 표시 (녹색 선)
- 할당 연결선 표시 (파란색 점선)
- 상태별 색상 변화

**4. 할당 연결선 (Assignment Lines)**
```
포대 -----> 위협
색상: 파란색 점선
스타일: 화살표
```

- DWTA 최적화 결과 시각화

- 실시간 업데이트 (1초 간격)

**5. 비행 궤적 (Trajectory)**
```

색상: 녹색 점선
```

**기능**:
- 미사일 비행 경로 표시
- 탄도 궤적 시각화
- 예상 도착 지점 표시

### 2-3. Objective Function Value Over Time (우측 패널)

#### **그래프 구성**

```
  Expected Damage (MIN_DAMAGE)
   25 ┌────────────────────────────────┐
      │                            ╱   │
      │                        ╱───    │
   20 │                    ╱───        │
      │                ╱───            │
      │            ╱───                │
   15 │        ╱───                    │
      │    ╱───                        │
      │╱───                            │
   10 │                                │
      │                                │
      │                                │
    5 │                                │
      │                                │
      │                                │
    0 └────────────────────────────────┘
      0    10   20   30   40   50
              Time Step
```

#### **기능**

**1. 목적함수 값 추이 표시**
- X축: 시간 스텝 (Time Step)
- Y축: 목적함수 값
  - MIN_DAMAGE: 기댓값 손실 (Expected Damage)
  - MAX_KILLS: 요격 확률 합 (Total Kill Probability)

**2. 실시간 업데이트**
- 1초 간격 업데이트
- 최대 800개 데이터 포인트
- 자동 스케일 조정

**3. 분석 정보**

**MIN_DAMAGE 모드**:
```
값 증가 = 손실 증가 (나쁨)
  - 요격 실패 발생
  - 고가치 자산 위협
  - 포대 탄약 부족

값 감소 = 손실 감소 (좋음)
  - 요격 성공
  - 위협 감소
  - 효율적 할당
```

**MAX_KILLS 모드**:
```
값 증가 = 요격 확률 증가 (좋음)
  - 더 많은 할당
  - 효율적 배치
  - 다층 방어

값 감소 = 요격 확률 감소 (나쁨)
  - 탄약 고갈
  - 포대 부족
  - 거리 제약
```

**4. 계단 형태 (Step Function)**
- 이유: DWTA 최적화가 이산 시점에 실행
- 최적화 시점: 1초 간격
- 값 변화: 할당 변경 시

## 8. 문제 해결

### 일반적인 문제

**1. 윈도우가 안 보임**
```
해결: 작업 표시줄에서 윈도우 클릭
원인: 다중 모니터 환경
```

**2. 그래프가 업데이트 안 됨**
```
해결: 시뮬레이션 재시작
원인: matplotlib 렌더링 오류
```

**3. 속도가 너무 느림**
```
해결: 속도 슬라이더 조절 (2.0x ~ 5.0x)
원인: 실시간 렌더링 부하
```

**4. 로그 저장 실패**
```
해결: 관리자 권한으로 실행
원인: 파일 쓰기 권한 부족
```
