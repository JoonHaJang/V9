## 1. 제약 조건 분류 체계

### 1.1 전체 분류

```
DWTA 제약 조건
├─ 1. 정적 제약 (Static Constraints)
│   ├─ 1.1 자원 제약
│   ├─ 1.2 물리적 제약
│   └─ 1.3 논리적 제약
│
├─ 2. 동적 제약 (Dynamic Constraints)
│   ├─ 2.1 시간 종속 제약
│   ├─ 2.2 상태 종속 제약
│   └─ 2.3 이벤트 기반 제약
│
└─ 3. 확률적 제약 (Stochastic Constraints)
    ├─ 3.1 불확실성 모델링
    └─ 3.2 신뢰도 제약
```

---

### 1.2 제약 우선순위

**Hard Constraints** (절대 위반 불가):
```
1. 탄약 용량 제약
2. 동시 교전 능력 제약
3. 표적별 동시 교전 금지
4. 교전 범위 제약
```

**Soft Constraints** (위반 시 페널티):
```
1. 교전 창 품질 제약 (K-factor)
2. 우선순위 제약
3. 자산 가치 최적화
```

## 2. 정적 제약 조건

### 2.1 자원 제약

#### 2.1.1 살보 발사 시간 간격 제약 (Salvo Firing Interval Constraint)

**수학적 정식화**:
$$t_{\text{fire}}^{(2)} = t_{\text{fire}}^{(1)} + \Delta t_{\text{salvo}}$$

**where**:
- $\Delta t_{\text{salvo}} \in [5, 22]$ 초 (시스템별 상이)

**파라미터** (`config_mip.py`):
```python
# 실제 구현에서는 살보 간격 3초 사용
evaluation_delay_sec = 3.0  # 첫발 → 3초 → 둘째발
missiles_per_engagement = 2  # 2발 살보 (고정)
```

**알고리즘 적용**:
```
✅ MIP: 실행 단계에서 적용 (최적화 단계 무관)
✅ GA: 실행 단계에서 적용 (최적화 단계 무관)
✅ Greedy: 실행 단계에서 적용 (최적화 단계 무관)

→ 물리적 제약이므로 모든 알고리즘에 동일 적용
```

**구현** (`multi_missile_tracker_gui.py:1091-1098`):
```python
# 모든 알고리즘 공통 실행 코드

# 각 발사별 Pk 샘플링 (3초 간격)
```

#### 2.1.2 탄약 용량 제약 (Ammunition Capacity Constraint)

**수학적 정식화**:
$$\sum_{i \in \mathcal{T}} m \cdot x_{iu} \leq M_u, \quad \forall u \in \mathcal{U}$$
$$\sum_{i \in \mathcal{T}} m \cdot x_{il} \leq M_l, \quad \forall l \in \mathcal{L}$$

**where**:
- $m = 2$: 살보당 미사일 수 (고정값)
- $M_u$: 상층 시스템 가용 미사일 수
- $M_l$: 하층 시스템 가용 미사일 수

**실제 가용량** (`config_mip.py`):
```python
LSAM: total_missiles = 24  # 발사대 4개 × 6발
MSAM: total_missiles = 48  # 발사대 6개 × 8발
```

**코드 구현** (`nonlinear_mip_optimizer.py:806-808`):
```python
total_missiles_needed = pulp.lpSum(total_engagements) * 2  # m=2
self.model += total_missiles_needed <= system.available_missiles
```

**수학적 정식화 (계속)**:
$$\sum_{i \in \mathcal{T}} m \cdot x_{ij} \leq M_j, \quad \forall j \in \mathcal{U} \cup \mathcal{L}$$

**where**:
- $m = 2$: 살보당 미사일 수
- $M_j$: 시스템 $j$의 가용 미사일 수
- $x_{ij} \in \{0, 1\}$: 할당 변수

**파라미터**:
```python
# 초기 탄약량
LSAM: 24발 (4발/발사대 × 6발사대)
MSAM: 24발 (4발/발사대 × 6발사대)

# 살보 크기
missiles_per_engagement = 2
```

**MIP 구현** (`@nonlinear_mip_optimizer.py:900-920`):
```python
def _add_ammunition_constraints(self):
    """탄약 용량 제약 추가"""
    
    for system in self.interceptor_systems:
        system_id = getattr(system, 'id', '')
        available_missiles = getattr(system, 'available_missiles', 0)
        
        # 상층 시스템
        if system in self.upper_systems:
            total_missiles_used = pulp.lpSum([
                self.missiles_per_engagement * 
                self.variables['x_upper'].get((asset_id, threat_id, system_id), 0)
                for asset_id in [getattr(a, 'id', '') for a in self.assets]
                for threat_id in [getattr(t, 'id', '') for t in self.threats]
            ])
            
            self.model += (
                total_missiles_used <= available_missiles,
                f"Ammunition_Upper_{system_id}"
            )
        
        # 하층 시스템 (동일)
        elif system in self.lower_systems:
            # ... (상층과 동일한 로직)
```

#### 2.1.3 동시 교전 능력 제약 (Simultaneous Engagement Limit)

**수학적 정식화**:
$$\sum_{i \in \mathcal{T}} x_{ij}(t) \leq C_j, \quad \forall j, \forall t$$

**where**:
- $C_j = 3$: 포대 $j$의 최대 동시 교전 수
- $x_{ij}(t)$: 시간 $t$에서의 할당 상태

**파라미터**:
```python
# 동시 교전 능력
max_simultaneous_engagements = 3  # 모든 포대 공통
```

**MIP 구현** (`@nonlinear_mip_optimizer.py:871-894`):
```python
def _add_battery_simultaneous_engagement_limits(self):
    """포대별 동시 교전 능력 제약조건 추가"""
    
    for battery in self.batteries:
        battery_id = battery["id"]
        specs = battery["specs"]
        
        # 포대 설정에서 동시 교전 능력 확인
        max_simultaneous = specs["battery_config"]["simultaneous_engagements"]
        
        # 해당 포대의 동시 교전 수 제한
        total_simultaneous = pulp.lpSum([
            self.variables['x_upper'].get((asset_id, threat_id, battery_id), 0)
            for asset_id in [getattr(a, 'id', '') for a in self.assets]
            for threat_id in [getattr(t, 'id', '') for t in self.threats]
            if getattr(t, 'target_asset_id', '') == asset_id
        ]) + pulp.lpSum([
            self.variables['x_lower'].get((asset_id, threat_id, battery_id), 0)
            for asset_id in [getattr(a, 'id', '') for a in self.assets]
            for threat_id in [getattr(t, 'id', '') for t in self.threats]
            if getattr(t, 'target_asset_id', '') == asset_id
        ])
        
        self.model += (
            total_simultaneous <= max_simultaneous,
            f"Simultaneous_Engagement_{battery_id}"
        )
```

**GA/Greedy 구현**:
```python
# 동시 교전 수 추적
battery_engagement_count = {b['id']: 0 for b in self.batteries}

# 할당 전 확인
if battery_engagement_count[system_id] < max_simultaneous:
    # 할당 가능
    battery_engagement_count[system_id] += 1
else:
    # 용량 초과, 할당 불가
    continue
```

**실시간 추적** (`@multi_missile_tracker_gui.py:1449-1453`):
```python
def _count_simultaneous_engagements(self, battery_id):
    """배터리의 현재 동시 교전 수"""
    count = 0
    
    if battery_id in self.primary_assignments:
        threat_list = self.primary_assignments[battery_id]
        
        # 활성 위협만 카운트
        for threat_id in threat_list:
            if threat_id in self.missiles:
                missile = self.missiles[threat_id]
                if missile.get('active', False):
                    count += 1
    
    return count
```

### 2.2 물리적 제약

#### 2.2.1 교전 범위 제약 (Engagement Range Constraint)

**수학적 정식화**:
$$x_{ij} = 0, \quad \text{if } d_{ij} > R_j$$

**where**:
- $d_{ij}$: 위협 $i$와 시스템 $j$ 간 거리
- $R_j$: 시스템 $j$의 최대 교전 범위

**파라미터**:
```python
# 교전 범위 (km)
LSAM: 150 km
MSAM: 120 km
```

**거리 계산** (`@config_mip.py:1374-1376`):
```python
# 2D 거리 계산
threat_launch_pos = np.array(threat['launch_position'][:2])
bat_pos = np.array(battery['position'][:2])
dist_2d = np.linalg.norm(bat_pos - threat_launch_pos)

# 교전 가능 여부
if dist_2d <= max_range:
    engagement_feasible = True
else:
    engagement_feasible = False
```

**MIP 구현**:
```python
# 교전 불가능한 조합은 변수 생성 안 함
if distance > max_range:
    # x_ij 변수 생성하지 않음
    continue
```

**GA/Greedy 구현**:
```python
def _get_feasible_systems(self, systems, threat_id, ...):
    """교전 가능한 시스템 목록 반환"""
    feasible = []
    
    for system in systems:
        # 거리 확인
        distance = self._calculate_distance(system, threat_id)
        max_range = getattr(system, 'engagement_range', 0)
        
        if distance <= max_range:
            feasible.append(system)
    
    return feasible
```

- $[h_j^{\min}, h_j^{\max}]$: 시스템 $j$의 교전 가능 고도 범위

### 2.3 논리적 제약

#### 2.3.1 표적별 동시 교전 금지 (Single Engagement per Threat)

**수학적 정식화**:
$$\sum_{j \in \mathcal{U} \cup \mathcal{L}} x_{ij} \leq 1, \quad \forall i$$

**의미**: 한 위협에 최대 1개 배터리만 할당

**MIP 구현** (`@nonlinear_mip_optimizer.py:848-869`):
```python
def _add_target_engagement_limits(self):
    """표적별 동시 교전 금지 제약"""
    
    for threat in self.threats:
        threat_id = getattr(threat, 'id', '')
        target_asset_id = getattr(threat, 'target_asset_id', '')
        
        # 상층 + 하층 할당 합계
        total_concurrent_engagements = pulp.lpSum([
            self.variables['x_upper'].get((target_asset_id, threat_id, system_id), 0)
            for system_id in [getattr(s, 'id', '') for s in self.upper_systems]
        ]) + pulp.lpSum([
            self.variables['x_lower'].get((target_asset_id, threat_id, system_id), 0)
            for system_id in [getattr(s, 'id', '') for s in self.lower_systems]
        ])
        
        # 한 표적에 동시에 하나의 배터리만 교전 가능
        self.model += (
            total_concurrent_engagements <= 1,
            f"Single_Engagement_{threat_id}"
        )
```

**GA/Greedy 구현** (`@ga_optimizer.py:238-246`):

## 3. 동적 제약 조건

### 3.1 시간 종속 제약

#### 3.1.1 교전 가능 시간 창 (Engagement Window)

**수학적 정식화**:
$$W_{ij}(t) = \begin{cases}
1 & \text{if } t_{\min}^{ij} \leq t \leq t_{\max}^{ij} \\
0 & \text{otherwise}
\end{cases}$$

**시간 창 계산**:
```python
# 최소 교전 시간
t_min = threat['launch_time'] + 10  # 발사 후 10초

# 최대 교전 시간
t_max = threat['estimated_impact_time'] - 5  # 충돌 5초 전

# 현재 시간 확인
if t_min <= current_time <= t_max:
    engagement_window_open = True
else:
    engagement_window_open = False
```

**K-factor 모델링**:
$$k_{ij}(t) = k_{\min} + (k_{\max} - k_{\min}) \cdot \left(1 - \frac{d_{ij}(t)}{R_j}\right)$$

**구현** (`@config_mip.py:1400-1420`):
```python
def calculate_k_factor(distance, max_range, k_min=0.6, k_max=1.0):
    """K-factor 계산"""
    if distance > max_range:
        return 0.0
    
    # 거리 기반 선형 보간
    k = k_min + (k_max - k_min) * (1 - distance / max_range)
    
    # 범위 제한
    k = max(k_min, min(k_max, k))
    
    return k
```

#### 3.1.2 비행 진행률 제약 (Flight Progress Constraint)

**수학적 정식화**:
$$\text{flight\_progress}(t) = \frac{t - t_{\text{launch}}}{t_{\text{impact}} - t_{\text{launch}}} \geq 0.6$$

**의미**: 60% 이상 진행 시 교전 가능

**구현** (`@multi_missile_tracker_gui.py:1040-1069`):

```python
flight_time = missile.get('flight_time', 300)
elapsed = self.simulation_time - missile.get('launch_time', 0)
flight_progress = elapsed / flight_time

# 교전 범위 확인
if flight_progress >= 0.6:
    # 교전 가능
    can_engage = True
else:
    # 교전 불가
    can_engage = False
```

**진행률 업데이트**:
```python
def update_simulation(self, dt):
    """매 프레임 진행률 업데이트"""
    for missile_id, missile in self.missiles.items():
        elapsed = self.simulation_time - missile['launch_time']
        missile['flight_progress'] = elapsed / missile['flight_time']
```

#### 3.2.2 위협 활성 상태 제약

**정의**:
```python

    missile.get('active', False) and
    not missile.get('intercepted', False) and
    not missile.get('deviated', False) and
    missile.get('flight_progress', 0) < 1.0
```

**상태 전이**:
```
발사 (active=True)
    ↓
비행 중 (active=True)
    ↓
├─ 요격 성공 (intercepted=True, active=False)
├─ 궤적 이탈 (deviated=True, active=False)
└─ 충돌 (flight_progress=1.0, active=False)
```

**필터링**:

## 4. 확률적 제약 조건

### 4.1 불확실성 모델링

#### 4.1.1 요격 확률 불확실성

**베타 분포 샘플링**:
$$p_j \sim \text{Beta}(\alpha, \beta) \cdot p_j^{\text{nominal}}$$

**파라미터**:
```python
alpha = 9.0
beta = 1.0
# 평균: E[p] = 0.9 × p_nominal
```

**구현** (`@uncertainty_modeling.py`):
```python
def sample_intercept_probability(base_prob, alpha=9.0, beta=1.0):
    """베타 분포 기반 요격 확률 샘플링"""
    sampled = np.random.beta(alpha, beta)
    return sampled * base_prob
```

---

#### 4.1.2 궤적 이탈 확률

**정의**:
$$P_{\text{deviation}} = 0.001 \quad \text{(0.1% per second)}$$

**구현**:
```python
# 매 프레임 확인
if random.random() < 0.001:
    missile['deviated'] = True
    missile['active'] = False
    self.log_message(f"{missile_id} 궤적 이탈", "WARNING")
```

### 4.2 신뢰도 제약

#### 4.2.1 최소 요격 확률 제약

**정의**:
$$P_{\text{intercept}}^{\text{eff}} \geq P_{\text{min}} = 0.5$$

**의미**: 유효 요격 확률이 50% 미만이면 할당하지 않음

**구현**:

## 5. 알고리즘별 제약 구현

### 5.1 MIP (Mixed Integer Programming)

**제약 추가 순서**:
```python
def create_model(self):
    # 1. 변수 생성
    self._create_decision_variables()
    
    # 2. McCormick 선형화
    self._add_mccormick_constraints()
    
    # 3. 자원 제약
    self._add_ammunition_constraints()
    
    # 4. 동시 교전 제약
    self._add_battery_simultaneous_engagement_limits()
    
    # 5. 표적별 교전 제약
    self._add_target_engagement_limits()
    
    # 6. Binary Tree 제약
    self._add_binary_tree_constraints()
    
    # 7. 목적함수 설정
    self._set_linearized_objective()
```

**제약 개수**:
```
표적별 동시 교전: O(T)
포대별 동시 교전: O(S)
탄약 용량: O(S)
McCormick 제약: O(T × S) × 4
Binary Tree 제약: O(I × T) × 4
───────────────
총: O(T × S + I × T)
```

### 5.2 GA (Genetic Algorithm)

**제약 처리 방식**:
```
1. Feasibility Check (할당 전)
   ├─ 교전 범위 확인
   ├─ 탄약 용량 확인
   ├─ 동시 교전 수 확인
   └─ 중복 할당 확인

2. Repair Mechanism (할당 후)
   ├─ 위반 발견 시 할당 제거
   └─ 대체 시스템 탐색
```

**구현**:
```python
def _create_random_individual(self):
    """제약 만족하는 개체 생성"""
    
    # 제약 추적
    battery_usage = {}
    battery_engagement_count = {}
    threat_assigned = {}
    
    for threat in self.threats:
        # Feasibility check
        feasible_systems = self._get_feasible_systems(
            systems, threat_id,
            battery_usage, battery_capacity, battery_engagement_count
        )
        
        if feasible_systems:
            # 제약 만족하는 시스템 중 랜덤 선택
            selected = random.choice(feasible_systems)
            
            # 할당 및 제약 업데이트
            assignments[key] = selected_id
            battery_usage[selected_id] += missiles_per_engagement
            battery_engagement_count[selected_id] += 1
            threat_assigned[threat_id] = selected_id
```

### 5.3 Greedy

**제약 처리 방식**:
```
1. First-Fit Strategy
   ├─ 첫 번째 교전 가능 시스템 선택
   └─ 제약 위반 시 다음 시스템 시도

2. Sequential Allocation
   ├─ 위협 순서대로 할당
   └─ 제약 만족 보장
```

**구현**:
```python
def solve(self):
    """Greedy 할당 (제약 만족 보장)"""
    
    # 제약 추적
    battery_usage = {}
    battery_engagement_count = {}
    threat_assigned = {}
    
    for threat in self.threats:
        # 상층 우선 시도
        for system in self.upper_systems:
            # Feasibility check
            if self._is_feasible(system, threat, battery_usage, ...):
                # 할당
                assignments[key] = system_id
                
                # 제약 업데이트
                battery_usage[system_id] += missiles_per_engagement
                battery_engagement_count[system_id] += 1
                threat_assigned[threat_id] = system_id
                break  # First-fit
```
