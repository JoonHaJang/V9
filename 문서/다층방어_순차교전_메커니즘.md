# 다층 방어 순차 교전 메커니즘 (Multi-Layer Sequential Engagement)

## 개요

본 문서는 수정된 다층 방어 시스템의 순차 교전 메커니즘을 상세히 설명합니다.

---

## 1. 할당 단계 (Assignment Phase)

### 1.1 최적화 알고리즘 할당 전략

**각 위협에 대해**:
```
위협 T001 발견
    ↓
최적화 실행 (MIP/Greedy/GA)
    ↓
├─ 상층(LSAM) 할당: LSAM_01 (최대 1개)
└─ 하층(MSAM) 할당: MSAM_01 (최대 1개)
```

**제약 조건**:
```python
# 상층 최대 1개 배터리
∑[u∈LSAM] x_iu ≤ 1

# 하층 최대 1개 배터리
∑[l∈MSAM] x_il ≤ 1

# 결과: 각 위협에 상층 1개 + 하층 1개 동시 할당 가능
```

## 2. 교전 단계 (Engagement Phase)

### 2.1 순차 교전 프로세스

**전체 흐름**:
```
위협 T001 교전 범위 진입 (flight_progress ≥ 0.6)
    ↓
┌─────────────────────────────────────────┐
│ 1단계: 상층(LSAM) 교전                  │
├─────────────────────────────────────────┤
│ • LSAM_01 발사 (2발 살보)               │
│ • P_kill_upper 계산                     │
│ • 결과 즉시 판정 (P_kill ≥ 0.5)        │
└─────────────────────────────────────────┘
    ↓
    ├─ 성공 (P_kill_upper ≥ 0.5) → 종료 ✅
    └─ 실패 (P_kill_upper < 0.5) → 2단계 진행
        ↓
┌─────────────────────────────────────────┐
│ 2단계: 하층(MSAM) 즉시 교전             │
├─────────────────────────────────────────┤
│ • 로그: "UPPER LAYER MISS → LOWER"      │
│ • MSAM_01 발사 (2발 살보)               │
│ • P_kill_total 계산                     │
│ • 최종 결과 판정                        │
└─────────────────────────────────────────┘
    ↓
    ├─ 성공 (P_kill_total ≥ 0.5) → 종료 ✅
    └─ 실패 (P_kill_total < 0.5) → 자산 피격 ❌
```

## 3. 코드 구현

### 3.1 배터리 분리 (`multi_missile_tracker_gui.py:1091-1096`)

```python
# 상층 배터리와 하층 배터리 분리
upper_batteries = [bid for bid in assigned_batteries 
                  if any(b['id'] == bid and b['system_type'] == 'LSAM' 
                         for b in self.batteries)]
lower_batteries = [bid for bid in assigned_batteries 
                  if any(b['id'] == bid and b['system_type'] == 'MSAM' 
                         for b in self.batteries)]
```

---

### 3.2 상층 교전 (`multi_missile_tracker_gui.py:1103-1136`)

```python
# 1단계: 상층(LSAM) 교전
P_survival = 1.0
missiles_fired = 0
upper_success = False

for battery_id in upper_batteries:
    battery = next((b for b in self.batteries if b['id'] == battery_id), None)
    
    if battery and battery.get('status') == 'OPERATIONAL' and \
       battery.get('available_missiles', 0) > 0:
        
        # 2발 살보 발사
        missiles_to_fire = min(2, battery.get('available_missiles', 0))
        battery['available_missiles'] -= missiles_to_fire
        missiles_fired += missiles_to_fire
        
        base_Pk = 0.85  # LSAM 기본 요격 확률
        
        # 각 발사별 Pk 샘플링
        for shot_num in range(missiles_to_fire):
            Pk_shot = self.uncertainty_model.sample_intercept_probability(base_Pk)
            P_survival *= (1 - Pk_shot)
        
        self.control_panel.log_message(
            f"[DEBUG] FIRE (UPPER): {battery_id} → {missile_id}",
            "DEBUG"
        )

# 상층 교전 결과 판정
P_kill_upper = 1.0 - P_survival
if P_kill_upper >= 0.5 and missiles_fired > 0:
    upper_success = True
    self.control_panel.log_message(
        f"[INFO] UPPER LAYER SUCCESS: {missile_id} (Pk={P_kill_upper:.4f})",
        "SUCCESS"
    )
```

---

### 3.3 하층 교전 (`multi_missile_tracker_gui.py:1138-1177`)

```python
# 2단계: 상층 실패 시 즉시 하층(MSAM) 교전
if not upper_success and lower_batteries:
    self.control_panel.log_message(
        f"[INFO] UPPER LAYER MISS: {missile_id} (Pk={P_kill_upper:.4f}) "
        f"→ Engaging LOWER LAYER",
        "WARNING"
    )
    
    for battery_id in lower_batteries:
        battery = next((b for b in self.batteries if b['id'] == battery_id), None)
        
        if battery and battery.get('status') == 'OPERATIONAL' and \
           battery.get('available_missiles', 0) > 0:
            
            # 2발 살보 발사
            missiles_to_fire = min(2, battery.get('available_missiles', 0))
            battery['available_missiles'] -= missiles_to_fire
            missiles_fired += missiles_to_fire
            
            base_Pk = 0.78  # MSAM 기본 요격 확률
            
            # 각 발사별 Pk 샘플링 (상층 P_survival 이어서 계산)
            for shot_num in range(missiles_to_fire):
                Pk_shot = self.uncertainty_model.sample_intercept_probability(base_Pk)
                P_survival *= (1 - Pk_shot)
            
            self.control_panel.log_message(
                f"[DEBUG] FIRE (LOWER): {battery_id} → {missile_id}",
                "DEBUG"
            )

# 최종 결과 판정
P_kill_total = 1.0 - P_survival
if P_kill_total >= 0.5 and missiles_fired > 0:
    result = 'INTERCEPTED'
    missile['active'] = False
    self.stats['intercepted'] += 1
else:
    result = 'MISSED'
    self.stats['missed'] += 1
```

## 4. 수학적 모델링

### 4.1 생존 확률 계산

**상층 교전 후 생존 확률**:
```
P_survival_upper = ∏[i=1 to 2] (1 - Pk_LSAM_i)
```

**하층 교전 후 최종 생존 확률**:
```
P_survival_total = P_survival_upper × ∏[j=1 to 2] (1 - Pk_MSAM_j)
                 = ∏[i=1 to 2] (1 - Pk_LSAM_i) × ∏[j=1 to 2] (1 - Pk_MSAM_j)
```

**요격 확률**:
```
P_kill_total = 1 - P_survival_total
```

---

### 4.2 예시 계산

**시나리오**: T001에 LSAM_01 + MSAM_01 할당

**상층 교전**:
```
LSAM_01 발사 #1: Pk = 0.87
LSAM_01 발사 #2: Pk = 0.85

P_survival_upper = (1 - 0.87) × (1 - 0.85)
                 = 0.13 × 0.15
                 = 0.0195

P_kill_upper = 1 - 0.0195 = 0.9805 (98.05%)

→ P_kill_upper ≥ 0.5 → 상층 성공 ✅
→ 하층 교전 불필요
```

**상층 실패 시나리오**:
```
LSAM_01 발사 #1: Pk = 0.30 (낮은 확률)
LSAM_01 발사 #2: Pk = 0.28

P_survival_upper = (1 - 0.30) × (1 - 0.28)
                 = 0.70 × 0.72
                 = 0.504

P_kill_upper = 1 - 0.504 = 0.496 (49.6%)

→ P_kill_upper < 0.5 → 상층 실패 ❌
→ 즉시 하층 교전 진행

하층 교전:
MSAM_01 발사 #1: Pk = 0.80
MSAM_01 발사 #2: Pk = 0.78

P_survival_total = 0.504 × (1 - 0.80) × (1 - 0.78)
                 = 0.504 × 0.20 × 0.22
                 = 0.0222

P_kill_total = 1 - 0.0222 = 0.9778 (97.78%)

→ P_kill_total ≥ 0.5 → 최종 성공 ✅
```

## 6. 주요 특징

### 6.1 장점

1. **현실적 다층 방어**: 상층 먼저 시도, 실패 시 즉시 하층 대응
2. **자원 효율성**: 상층 성공 시 하층 자원 절약
3. **높은 요격률**: 두 계층 모두 실패해야 자산 피격
4. **명확한 로그**: 각 계층별 교전 결과 추적 가능

---

### 6.2 수학적 이점

**단일 계층 vs 다층 방어 비교**:

```
단일 계층 (LSAM만):
P_kill = 0.9805 (98.05%)
P_miss = 0.0195 (1.95%)

다층 방어 (LSAM + MSAM):
P_kill = 1 - (0.0195 × 0.0484) = 0.9991 (99.91%)
P_miss = 0.0009 (0.09%)

→ 실패 확률 21배 감소 (1.95% → 0.09%)
```
