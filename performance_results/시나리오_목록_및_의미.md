# DWTA 시나리오 목록 및 최적화 관점 의미

## 📊 시나리오 분류

### 1. 확장성 테스트 (Scalability Test)

| 시나리오 | 위협 수 | 목적 | 최적화 관점 의미 |
|---------|--------|------|----------------|
| **SMALL_3** | 3발 | 알고리즘 검증 | 최소 문제 크기, 알고리즘 정확성 검증 |
| **SMALL_5** | 5발 | 기본 성능 측정 | 기본 성능 벤치마크, 빠른 수렴 확인 |
| **SMALL_8** | 8발 | 전환점 분석 | 문제 복잡도 전환점, 휴리스틱 vs 정확해 차이 시작 |
| **MEDIUM_10** | 10발 | 일반 공격 시뮬레이션 | 실전 소규모 공격, 실시간 대응 가능성 검증 |
| **BASELINE_15** | 15발 | 표준 벤치마크 | **표준 비교 기준**, 균형잡힌 복잡도 |
| **MEDIUM_20** | 20발 | 균형 공격 시뮬레이션 | 중규모 최적화, 자원 제약 시작 |
| **HEAVY_30** | 30발 | 포화 공격 시뮬레이션 | 대규모 최적화, 계산 복잡도 급증 |
| **LARGE_40** | 40발 | 한계 테스트 | 알고리즘 확장성 한계, 메모리/시간 제약 |
| **STRESS_100** | 100발 | 성능 검증 | 극한 스트레스 테스트, 실용성 한계 확인 |

**최적화 의미**:
- **변수 수**: 위협 수 × 배터리 수 (15발 × 6배터리 = 90개 변수)
- **제약 조건**: 위협당 1개 배터리 할당, 배터리 미사일 제약
- **계산 복잡도**: O(n²) ~ O(n³) (n = 위협 수)
- **Branch-and-Bound 깊이**: 위협 수에 비례하여 증가

### 2. 공격 패턴 테스트 (Attack Pattern Test)

| 시나리오 | 위협 수 | 패턴 | 목적 | 최적화 관점 의미 |
|---------|--------|------|------|----------------|
| **SEQUENTIAL_20** | 20발 | 순차 발사 | 시간 분산 공격 | 동적 재최적화 빈도 낮음, 안정적 할당 |
| **SIMULTANEOUS_20** | 20발 | 동시 발사 | 포화 공격 | 동시 최적화 필요, 자원 경쟁 극대화 |

**최적화 의미**:
- **Sequential**: 시간적 여유 → 최적화 시간 충분 → MIP 유리
- **Simultaneous**: 즉각 대응 필요 → 빠른 휴리스틱 유리

| 시나리오 | 위협 수 | 배터리 | 목적 | 최적화 관점 의미 |
|---------|--------|--------|------|----------------|
| **DWTA_BALANCED** | 20발 | 6개 | 표준 비교 기준 | 균형잡힌 문제 크기, 알고리즘 간 공정 비교 |

**최적화 의미**:
- **균형 잡힌 복잡도**: 너무 쉽지도, 어렵지도 않음
- **실전 대표성**: 실제 작전 시나리오와 유사
- **비교 기준**: 논문/연구에서 표준 벤치마크로 사용

## 🎯 최적화 관점 핵심 의미

### 문제 크기별 특성

#### Small (3-8발)
- **변수 수**: 18-48개
- **최적화 시간**: < 1초
- **특징**: 모든 알고리즘이 최적해 도달 가능
- **의미**: 알고리즘 정확성 검증용

#### Medium (10-20발)
- **변수 수**: 60-120개
- **최적화 시간**: 1-10초
- **특징**: MIP와 휴리스틱 차이 시작
- **의미**: 실전 시나리오, 실시간성 vs 최적성 트레이드오프

#### Large (30-40발)
- **변수 수**: 180-240개
- **최적화 시간**: 10-60초
- **특징**: MIP 계산 부담 증가, 휴리스틱 우위 가능
- **의미**: 확장성 한계 테스트

#### Stress (100발)
- **변수 수**: 600개+
- **최적화 시간**: 분 단위
- **특징**: MIP 실용성 한계, 휴리스틱 필수
- **의미**: 극한 성능 검증

## 📈 현재 연구에서의 사용

### BASELINE_15 (현재 테스트)

**선택 이유**:
1. **적절한 복잡도**: 15발 × 6배터리 = 90개 변수
2. **실전 대표성**: 일반적인 공격 규모
3. **비교 가능성**: 알고리즘 간 차이 명확히 드러남
4. **계산 시간**: MIP 274ms, GA 642ms, Greedy 0.556ms
5. **통계적 신뢰성**: 7회 반복 실험 가능 (각 1.5분)

**최적화 특성**:
- **Branch-and-Bound 깊이**: 평균 15단계
- **LP Relaxation 품질**: McCormick 선형화로 tight bound
- **수렴 속도**: 95% 케이스에서 < 500ms
- **해의 품질**: 100% 요격률, 최적 자원 배분
