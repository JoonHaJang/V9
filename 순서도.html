다층 방어 미사일 체계

탄도 미사일 위협에 대응하는 계층적 방어 구조

다층 방어 체계란?

고도별 2단계 요격 체계로, 다중 기회를 제공하여 방어 확률을 극대화하는 시스템

방어 계층
  • 상층(LSAM): 고고도 40-60km, 사거리 100-150km, 확률 97.75%
  • 하층(MSAM): 저고도 10-20km, 사거리 40-80km, 확률 95.16%
핵심 전술

상층 1차 요격 → 실패 시 하층 2차 기회 → 레이어드 방어로 생존 확률 극대화

본 연구의 접근 방법론

NP-hard 문제를 실시간 최적화 가능하도록 만드는 4가지 핵심 기술

1️⃣ K-factor

교전 창 품질 수치화

k(t)=0.6+0.4(1-d/R)
  • d→0: k→1.0 (최적)
  • d→R: k→0.6 (제한)
  • 자원 대기 시 품질 저하
✓ 물리적 현실
2️⃣ McCormick

비선형→선형

w=x·k·P
↓ McCormick
4개 선형 제약식
  • NLIP→MILP
  • 전역 최적해 보장
  • CBC 솔버 적용
✓ Exact Solution
3️⃣ Binary Tree

생존 확률 최적화

∏(1-w₁)···(1-wₙ)
↓ Binary Tree
O(N) 변수+제약
  • O(N²)→O(N)
  • 변수 개수 감소
  • 메모리 효율성
✓ 계산 효율성
4️⃣ Warm-start

이전 해 재사용

xt←xt-1
kt←kt-1
(변경분만 재계산)
  • 수렴 5-10배 향상
  • 동적 재최적화
  • 실시간성 확보
